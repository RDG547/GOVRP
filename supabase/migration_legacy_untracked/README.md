# Migrações históricas sem versão correspondente no banco

Estes 10 arquivos foram movidos de `supabase/migrations/` para preservação,
porque seus números de versão não aparecem em `supabase_migrations.schema_migrations` do projeto principal em 13/11/2026.
Não significa que a lógica nunca tenha sido aplicada manualmente. Evite reaplicação automática.

O histórico canônico usado para reconstruir Supabase Preview foi restaurado a partir do banco,
com os scripts de conteúdo diferente substituídos por suas versões efetivamente aplicadas.
Os arquivos originais foram preservados nesta pasta e podem ser inspecionados individualmente.

Nenhuma alteração do esquema, saldos, histórico econômico ou configurações de produção é feita por esta reorganização no GitHub.
